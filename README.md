# Onepune

Discord bot สำหรับนัดเวลาเช็กสมาชิกทั้งเซิร์ฟเวอร์จากห้องเสียง

## วิธีใช้

พิมพ์คำสั่งที่ตรงรูปแบบนี้เท่านั้น:

- `วันเพื่อน 22:30` — ตั้งเวลาเช็ก และแจ้งผลในช่องที่พิมพ์คำสั่ง
- `วันเพื่อน 4 ทุ่ม` — ตั้งเวลาเช็กเวลา 22:00 ตามเวลาไทย
- `วันเพื่อน 22:30 #เช็กชื่อ` — ตั้งเวลาเช็ก และส่งผลไปยังช่องที่เลือก

เมื่อถึงเวลา บอทจะดึงสมาชิกทั้งเซิร์ฟเวอร์ (ไม่นับบอท) แล้วส่งรายงานว่าใครอยู่ในห้องเสียงและใครยังไม่มา

ข้อความอื่นที่ไม่ใช่ `วันเพื่อน` ตามด้วยเวลาที่ถูกต้อง บอทจะไม่ตอบกลับ

## ตั้งค่าให้บอทออนไลน์

1. เพิ่ม `DISCORD_BOT_TOKEN` ใน GitHub Actions Secrets
2. เปิด **Message Content Intent**, **Server Members Intent** และ **Voice State Intent** ใน Discord Developer Portal
3. ตรวจสอบว่า bot มีสิทธิ์อ่านสมาชิก อ่านสถานะห้องเสียง และส่งข้อความในช่องแจ้งเตือน
4. กด **Run workflow** ชื่อ `Onepune 24/7` ครั้งแรก หรือรอ workflow schedule

สถานะนัดหมายจะถูกเก็บไว้ใน `data/schedules.json` ผ่าน GitHub Contents API เพื่อให้โหลดกลับมาได้เมื่อ workflow เริ่มใหม่

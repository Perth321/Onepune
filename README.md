# Onepune

Discord bot สำหรับตั้งเวลาเช็กสมาชิกในเซิร์ฟเวอร์

วิธีใช้:
- @Onepune วันนี้วันเพื่อนตอน 4 ทุ่ม = ตั้งเวลาเช็กเวลา 22:00
- @Onepune วันนี้วันเพื่อนตอน 22:30 = ตั้งเวลาเช็กเวลา 22:30
- @Onepune เช็กชื่อทันที = เช็กตอนนี้
- @Onepune ยกเลิกเวลา = ยกเลิกนัด

สมาชิกที่อยู่ใน voice channel ตอนถึงเวลาจะถูกนับว่า มาแล้ว

เปิด Message Content Intent และ Server Members Intent ใน Discord Developer Portal

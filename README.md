# Onepune

บอท Discord สำหรับนัดเวลาเช็กสมาชิกทั้งเซิร์ฟเวอร์จากห้องเสียง โดยแยกนัดหมายของแต่ละเซิร์ฟเวอร์ออกจากกัน

## ใช้งานแบบกดปุ่ม

1. พิมพ์ `/onepune` ในเซิร์ฟเวอร์
2. กด **ตั้งเวลา**
3. ใส่เวลาไทย เช่น `22:30` หรือ `4 ทุ่ม`
4. เลือกช่องแจ้งผลจากเมนู
5. เมื่อถึงเวลา บอทจะรายงานสมาชิกที่อยู่และไม่อยู่ในห้องเสียง

เมนูเลือกช่องใช้รายการช่องล่าสุดจาก Discord ทุกครั้ง จึงเห็นช่องที่เพิ่งสร้างใหม่ได้โดยไม่ต้องแก้โค้ดหรือรีสตาร์ตบอท

ปุ่ม **ดูสถานะ** และ **ยกเลิกนัดหมาย** ใช้จัดการนัดหมายของเซิร์ฟเวอร์นั้นได้ทันที การตั้งค่าของแต่ละเซิร์ฟเวอร์ไม่ปนกัน

คำสั่งเดิมยังรองรับอยู่:

- `วันเพื่อน 22:30`
- `วันเพื่อน 4 ทุ่ม`
- `วันเพื่อน 22:30 #เช็กชื่อ`

## ตั้งค่า Discord

1. เพิ่ม `DISCORD_BOT_TOKEN` ใน GitHub Actions Secrets
2. เปิด **Message Content Intent**, **Server Members Intent** และ **Voice State Intent** ใน Discord Developer Portal
3. เชิญบอทด้วย scope `bot` และ `applications.commands`
4. ให้บอทมีสิทธิ์ดูเซิร์ฟเวอร์ ดูสมาชิก **Connect** เข้าห้องเสียง และส่งข้อความในช่องรายงาน หากจะใช้คำสั่งเสียงจัดการสมาชิกให้เพิ่ม **Mute Members** และ **Deafen Members** และวางยศบอทไว้สูงกว่าสมาชิกเป้าหมาย
5. คนที่จะตั้งค่าผ่าน `/onepune` ต้องมีสิทธิ์ **Manage Server**

## แปลภาษาและคุยกับวันเพื่อน

- เพิ่ม `OPENROUTER_API_KEY` ที่ GitHub repository > Settings > Secrets and variables > Actions > Secrets ห้ามใส่คีย์ลงในโค้ดหรือ commit
- ตั้ง `OPENROUTER_MODEL` ได้ตามต้องการ ค่าเริ่มต้นคือ `openrouter/free`
- ตั้ง `AUTO_TRANSLATE_ENABLED=false` หากต้องการปิดการแปลทุกข้อความ
- ข้อความภาษาไทยจะถูกแปลเป็นอังกฤษ และข้อความภาษาอังกฤษจะถูกแปลเป็นไทยอัตโนมัติ
- หากข้อความมีคำว่า `วันเพื่อน`, `วัน เพื่อน` หรือ mention บอท บอทจะสนทนาแทนการแปล
- วันเพื่อนคุยแบบเพื่อนสายกวน มีมุกและคำหยาบเบา ๆ แต่ไม่ใช้คำเหยียด คุกคาม หรือกลั่นแกล้งรุนแรง

### Agent tools จัดการเซิร์ฟเวอร์

เรียกชื่อวันเพื่อนแล้วสั่งด้วยภาษาปกติได้ เช่น `วันเพื่อน เซิร์ฟนี้มีกี่คน` หรือ `วันเพื่อน ตั้ง slowmode ช่องนี้ 10 วิ`

- ดูภาพรวมเซิร์ฟเวอร์ รายการช่อง รายการยศ และค้นหาสมาชิก
- สร้างช่องข้อความ เปลี่ยนชื่อช่อง ตั้ง slowmode และ timeout สมาชิก
- ค้นเว็บและสรุปผลพร้อมลิงก์แหล่งข้อมูล โดยพิมพ์เช่น `วันเพื่อน ค้นข่าว Roblox ล่าสุด`
- ปิด/เปิดไมค์หรือเสียงที่ได้ยินของสมาชิกในห้องเสียง เฉพาะเจ้าของเซิร์ฟเวอร์หรือผู้มีสิทธิ์ **Administrator** เท่านั้น
- รายการที่เปลี่ยนเซิร์ฟเวอร์จะยังไม่ทำทันที บอทจะแสดงรายละเอียดและปุ่มยืนยันที่หมดอายุใน 5 นาที
- เฉพาะผู้สั่งเท่านั้นที่กดปุ่มได้ และบอทตรวจสิทธิ์ **Manage Channels** หรือ **Moderate Members** ซ้ำตอนยืนยัน
- บอทต้องมียศสูงพอและมีสิทธิ์ Discord สำหรับรายการนั้นด้วย

การค้นเว็บใช้ OpenRouter Web Search และมีค่าใช้จ่ายเพิ่มตามจำนวนครั้ง แม้เลือกโมเดลฟรี โดยตั้งไว้ไม่เกิน 3 ผลลัพธ์ต่อคำสั่งเพื่อจำกัดค่าใช้จ่าย

### คำสั่งเสียง

- เมื่อมีคนอยู่ในห้องเสียง บอทจะเข้าห้องที่มีคนอยู่ให้อัตโนมัติ และออกหลังห้องว่าง 30 วินาที
- พูดขึ้นต้นด้วยคำว่า `วันเพื่อน` เช่น “วันเพื่อน เซิร์ฟนี้มีกี่คน” คำตอบและปุ่มยืนยันจะแสดงในช่องข้อความของเซิร์ฟเวอร์
- บอทบันทึกคำพูดเป็นช่วงสั้นไม่เกิน 15 วินาทีและส่งไป OpenRouter เพื่อถอดเสียง จึงควรแจ้งสมาชิกและขอความยินยอมตามกฎของเซิร์ฟเวอร์
- ตั้ง `VOICE_COMMANDS_ENABLED=false` เพื่อปิดการเข้าห้องและรับเสียงทั้งหมด
- เปลี่ยนโมเดลถอดเสียงได้ด้วย `OPENROUTER_STT_MODEL` ค่าเริ่มต้นคือ `openai/whisper-large-v3` โดย STT มีค่าใช้จ่ายตามระยะเวลาเสียง

โมเดลฟรีมี rate limit ต่ำ เหมาะกับการทดลองหรือเซิร์ฟเวอร์ที่ข้อความไม่มาก หากใช้งานจริงควรตั้ง `OPENROUTER_MODEL` เป็นโมเดลแบบเสียเงินที่ต้องการ

ข้อความที่บอทแปลหรือใช้สนทนาจะถูกส่งไปยัง OpenRouter และผู้ให้บริการโมเดลที่ OpenRouter เลือก จึงไม่ควรส่งรหัสผ่าน token หรือข้อมูลลับในช่องที่เปิดใช้ฟีเจอร์นี้

## ทำงานต่อเนื่อง

Workflow `Onepune 24/7` จะเริ่มบอทใหม่อัตโนมัติทุก 6 ชั่วโมง ก่อน runner เดิมหมดเวลาสูงสุดของ GitHub Actions และบอทจะโหลดนัดหมายกลับจาก `data/schedules.json` ทุกครั้งที่เริ่มใหม่

GitHub-hosted runner มีข้อจำกัดเวลาการทำงานต่อ job จึงมีช่วงเริ่มงานใหม่สั้น ๆ ได้ หากต้องการออนไลน์แบบไม่มีช่วงต่อ ให้ใช้ `Dockerfile` นี้กับโฮสต์ที่รองรับ always-on process แทน

## ข้อมูลหลายเซิร์ฟเวอร์

ข้อมูลนัดหมายถูกเก็บแยกตาม `guildId` และบอทจะลงทะเบียน `/onepune` ให้ทั้งเซิร์ฟเวอร์ที่มีอยู่และเซิร์ฟเวอร์ที่เชิญเข้ามาใหม่
